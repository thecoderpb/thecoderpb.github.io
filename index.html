Academic work spanning systems security and applied machine learning for cyber defense.

Security · MITRE ATT&CK

Semantic Context-Aware SOC Alert Prioritization Using Embedding-Based MITRE ATT&CK Mapping

Western University · with A. A. A. J. Sadiq & K. R. Ahmed

Converts network flow and log records into semantic alert descriptions, applies a Random Forest tactic classifier, and uses FAISS-indexed Sentence Transformer embeddings to map alerts to the top-3 MITRE ATT&CK techniques — achieving 70.0% Top-1 and 84.6% Top-3 accuracy against official ground-truth mappings.

Western University · advised by Marwa Elsayed · Dec 2025

Surveys secure boot mechanisms, vulnerabilities, and verification approaches across Android, ARM TrustZone–based IoT devices, and embedded Linux — identifying open challenges and the need for standardized practices and automated verification frameworks.
